Abstract

Public multimodal driving datasets come almost exclusively from North America, Europe and East Asia, so the traffic of Latin American cities, with motorcycles filtering between lanes, buses stopping in mixed traffic, pedestrians and hand-pulled carts, cobblestones and faded markings, is essentially missing from them. We present the Buenos Aires Dataset, recorded in the Buenos Aires Metropolitan Area across residential streets, avenues, the historic center and highways, with a vehicle carrying a 64-beam LiDAR, five cameras, an industrial IMU, two RTK GNSS receivers, a microphone and its drive-by-wire bus.

Beyond the data, we treat time synchronization as a result rather than an assumption: we describe how every sensor stream is referenced to GNSS time and verify it over every recording. The release includes the calibration, a reference trajectory obtained by multi-sensor fusion, and a Python toolkit to read the data and evaluate trajectories.

Calibration

Camera intrinsics, the stereo pair, the LiDAR–camera extrinsics and the IMU noise model are released with the dedicated calibration recordings (calib/), so every calibration can be recomputed and checked with the toolkit.

Reference trajectory

Every sequence has a reference trajectory from multi-sensor fusion (MINS) of the IMU, the front stereo pair, the LiDAR, the wheel speeds and both GNSS receivers, with its covariance, in the ground_truth bags.

Download

  The data and the toolkit are being prepared for release and will be linked from this page soon.

The data are hosted on Hugging Face as ROS 2 MCAP bags, one per sensor group and split, so you can download only what you need. The cameras and the LiDAR account for 60 % and 40 % of the 2.9 TB; all the other groups together take less than 10 GB. MCAP embeds the message definitions, so every topic, including the u-blox and Dataspeed messages, can be decoded without ROS or the corresponding packages.

<root>/<sequence>/split_XX/<group>/<group>_0.mcap
    group: cameras, lidar, imu_gps, dataspeed, wheel, microphone, ground_truth, tf_static
<root>/calib/                     # calibration recordings

The toolkit's download command fetches any subset and resumes interrupted downloads:

pip install "badataset[download] @ git+https://github.com/udesa-linar/badataset_sdk"

badataset-download /data/buenos_aires                                     # everything (2.9 TB)
badataset-download /data/buenos_aires --sequences loop_caba \
    --groups imu_gps ground_truth tf_static                               # IMU, GNSS and reference only
badataset-download /data/buenos_aires --sequences caba --splits split_03  # one short split
badataset-download /data/buenos_aires --calib                             # calibration recordings

Toolkit

The badataset Python package reads the bags without a ROS installation, provides the calibration as matrices with LiDAR-to-camera projection, evaluates trajectories against the reference, and contains the scripts that reproduce every calibration from the released recordings and compare the result with the release. The MINS configuration of the reference trajectory is included.

from badataset import Dataset, sync
from badataset.groundtruth import Reference
from badataset import evaluate as E

seq = Dataset('/data/buenos_aires').sequence('loop_caba')
for t, imu in seq.messages('/imu/data'):          # any topic; t = GNSS-referenced stamp [s]
    ...
for f in sync.front_frames(seq, start=t0, end=t0 + 2):
    f.cam1, f.cam5, f.cloud.xyz                    # stereo pair + the LiDAR scan of its trigger

ref = Reference(seq)                               # reference trajectory, in any sensor frame
E.rpe_kitti(ref.traj, E.load_tum('mine.txt'))      # relative error over 100-800 m

Privacy

The sequences were recorded on public roads. Faces and license plates were blurred before release, but automatic detection can miss some of them. Please do not attempt to identify any person or vehicle. If you find a face or plate that is not blurred, or you appear in the data and want an image removed, write to linar@udesa.edu.ar with the sequence, split and time.
