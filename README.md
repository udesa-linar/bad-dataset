# The Buenos Aires Dataset: project page

Static page served by GitHub Pages (`index.html` + `static/`), adapted from the [Nerfies](https://github.com/nerfies/nerfies.github.io) template (CC BY-SA 4.0), the single entry point that links to the data on
Hugging Face and to the toolkit. To preview it locally, open `index.html` in a browser.
